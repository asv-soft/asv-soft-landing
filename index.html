Основной программный продукт

Основным программным продуктом компании является Asv.Drones.

Данное ПО решает обладает следующим функционалом:

  • Управление одиним и более БПЛА одновременно
  • Создание и редактирование миссий для БПЛА
  • Настройка БПЛА и работа с любыми устройствами в сети MAVLink
  • Подробная система логов
  • Инспекция пакетов, которые передаются по MAVLink в режиме реального времени
  • Поддержка системы плагинов, которые могут расширять функционал ПО

Asv.Mavlink

Асв Мавлинк является библиотекой, которая реализует протокол MAVLink. Это основной протокол, который используется для коммуникации дронов между собой. Наша библиотека является первой полноценной реализацией протокола MAVLink на C#, которая позволяет разрабатывать свои программы для управления БПЛА.

Asv.Avalonia

Асв Авалония является фреймворком, который основан на Avalonia. Фреймворк позволяет создавать гибкие и функциональный приложения.

Отличительные особенности Asv.Avalonia:

  • Интеграция с ASP.NET AppHost
  • Поддержка реактивности через R3
  • Система плагинов
  • Реализация undo/redo для различных действий пользователя
  • Гибкий этап настройки ПО, который позволяет создавать модульные приложения с возможностью замены составных частей
